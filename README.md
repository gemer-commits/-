# Стабилизация дрожащего видео на основе оптического потока

Итоговый проект по дисциплине «Компьютерное зрение 1».
Автор: Mukhanbetkerey Rakymzhan, группа DS-23B

Программа убирает дрожание камеры из видео: оставляет плавное движение (панораму),
а мелкие тряски вычитает. Только классические методы, без нейросетей.

![Этапы работы](figures/fig_pipeline.png)

## Как это работает

1. Находим на кадре углы (Ши–Томаси).
2. Следим за ними на следующем кадре (оптический поток Лукаса–Канаде).
3. По движению точек оцениваем сдвиг и поворот камеры (RANSAC игнорирует движущиеся объекты).
4. Складываем движения в траекторию камеры и сглаживаем её.
5. Каждый кадр возвращаем на сглаженную траекторию и слегка увеличиваем, чтобы убрать чёрные края.

## Запуск

```bash
pip install -r requirements.txt
python stabilizer.py моё_видео.mp4 результат.avi --radius 15
```

Параметры: `--radius` — насколько сильно сглаживать (в кадрах), `--method lk|orb` — метод.

Воспроизвести тесты и рисунки:

```bash
python make_test_videos.py   # создаёт 8 тестовых видео в data/
python evaluate.py           # считает метрики -> results/metrics.csv
python visualize.py          # рисунки и демо-видео
```

## Результаты (на синтетических тестах)

| Метрика | До | После |
|---|---|---|
| PSNR соседних кадров (обычное дрожание) | 23,2 дБ | 26,9 дБ |
| Быстрое дрожание траектории | 6,4 px | 0,9 px |
| Ошибка оценки движения камеры | — | 0,2–0,4 px |
| Скорость | — | 25–50 кадров/с (1 ядро CPU) |

Проверено на 8 сценариях: шум, засветка, движущиеся объекты, перекрытие 40% кадра,
размытие, бедная текстура, сильное дрожание.

## Ограничения

- Тесты синтетические, на реальных видео проверка ограниченная.
- Не учитываются параллакс и rolling shutter.
- В сценах без текстуры (белая стена, небо) точек для слежения мало.
- Платим ~10% поля зрения (zoom).
